Notifications

E-mail is on when host and recipients are set, the webhook when it has a URL; empty both to switch them off. The heartbeat URL is fetched every five minutes while the monitoring works; a dead man's switch service (healthchecks.io style, period 5 minutes) mails you when the pings stop, the one failure the server cannot report itself. The webhook also receives a stream of security events. Settings are stored sealed with the master key; the config file only seeds them on first start.

Thresholds

Fixed checks: disk, inodes, memory, memory and io pressure, swap, cpu, clock, services, Docker API, reboot pending, backups, certificates, deploys, AIDE, ssh brute force, bans, OOM kills, kernel errors, failed units, sensitive file changes (auditd), Falco, WAF spikes, 5xx bursts, containers dying, out of memory, unhealthy or restart-looping. Checks run every minute; opened and resolved alerts are sent once a minute as one message.
